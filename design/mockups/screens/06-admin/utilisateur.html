Profil d'un compte vu par un admin (la page est longue : faire défiler à la molette dans le téléphone). Pour un compte déjà admin, le premier bouton devient « Retirer le statut admin » (icône bouclier vide). Sur son propre compte, les deux boutons sont remplacés par le texte « C'est votre compte : utilisez Réglages > Profil pour le gérer. ». « Promouvoir admin » ouvre une boîte de confirmation Android ; « Supprimer l'utilisateur » ouvre l'écran rouge (voir supprimer-utilisateur.html).
