Importer mes flashes
Récupérez automatiquement vos flashes depuis l'application officielle FlashInvaders installée sur votre téléphone Android, via votre PC.
1
Connectez-vous à InvadersHunter
Avec le compte sur lequel vous voulez importer vos flashes.
2
Branchez votre téléphone au PC
Câble USB. Autorisez le transfert de données si demandé.
3
Activez le débogage USB
Réglages → À propos → tapez 7 fois sur "Numéro de build" pour activer les options développeur, puis activez "Débogage USB". Acceptez la demande sur le téléphone.
4
Téléchargez et lancez l'application
Sur votre PC Windows, double-cliquez sur le .exe téléchargé. Windows SmartScreen affichera un avertissement (application non signée) : cliquez "Informations complémentaires" → "Exécuter quand même". Saisissez vos identifiants InvadersHunter quand demandé. Choisissez ensuite [1] pour ajouter seulement les flashes manquants, ou [2] pour une synchronisation complète qui retire aussi les flashes absents du téléphone (aperçu du compte et des totaux, puis confirmation).
5
IMPORTANT : synchronisez l'app
Une fois l'import terminé, revenez sur l'écran Profil et appuyez sur "Synchroniser" pour récupérer les flashes importés dans l'application.
Télécharger l'application (Windows)
Aucun prérequis : le script télécharge automatiquement les outils Android nécessaires (~10 Mo, une seule fois). Windows uniquement pour le moment.
Alternative : coller une liste
Si l'ADB ne fonctionne pas, collez une liste de noms d'invaders (un par ligne ou séparés par des virgules). Les extensions de fichier sont ignorées.
PA_1234 LYO_56 NY_789
Importer la liste

Écran empilé, sans barre d'onglets. Toute la page défile (faites défiler dans le téléphone) : 5 étapes, bouton de téléchargement, puis le plan B « coller une liste » en bas. Textes en police système (choix du code pour la lisibilité), sauf numéros et boutons en police pixel. La zone de texte montre son texte d'exemple en gris.
